# 合成声明校验样本

本目录保存用于测试声明核验逻辑的 **88 条合成回归用例**，以及核心文件的校验哈希清单。

- `claim_synthetic_cases.jsonl`：案例编号、声明文本、权威事实、预期判定和文本哈希，用于验证不同执行状态下的声明判定是否符合预期。
- `v3_protected_hashes.json`：记录受保护核心资产的内容哈希，便于核对版本一致性。

本组用例仅用于声明核验的回归测试，不是 Benchmark112 的真实模型回答，也不用于推断真实业务场景下的准确率。

来源说明：这88条用例来自前版AI草拟、待人工复核的合成fixture。中性化仅改文件名并移除审核元数据；声明文本、权威事实、预期标签及文本哈希不变。预期标签不是人工校准真值，不能用于解锁正式校准。原制作来源由本说明保留，不将缺省审核字段解释为已经审核。
