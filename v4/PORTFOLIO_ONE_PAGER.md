# 项目概览｜Agent Skill Governance

**定位**：高风险工具调用型 Agent 的通用 Skill 治理与受控自进化框架。它让模型负责解释和补丁建议，让权威后端与确定性策略负责权限、审批、执行前复核及最终提交。

## 为什么要做

起点是 SAC 储能调度 Agent 的候选方案审查：仅靠生成式提示词无法保证 Validator、风险门控、人工确认和原子激活的流程正确性；调度审查本身还存在经济与 SOC 解释遗漏。工程演进依次解决了**执行安全、跨场景复用和只读 Skill 的受控质量迭代**。

## 架构亮点

- **双路 Skill**：确定性 `action-risk-gate` 决定 PASS/REVIEW/BLOCK；只读 `action-review` 和 `sac-plan-review` 解释权威事实，不获得写权限。
- **通用治理**：Pydantic 请求契约、`DomainAdapter`、审批参数绑定、状态复核、CAS 与幂等。
- **领域适配**：配置变更、科研参数均有合成示例；SAC 专业场景已完成历史真实 Actor / HTTP 隔离集成。
- **受控自进化**：反馈→归因→独立经验→受限 Prompt 补丁→隔离对照→质量门控→审批；历史真实 Candidate 未正式晋升。
